# Página de Serviços — Leoclecio Ambrosio

Página única e responsiva criada com HTML, CSS puro e JavaScript.

## Como visualizar

Abra o arquivo `index.html` no navegador. Para desenvolvimento, também é possível
usar a extensão Live Server do VS Code.

## Arquivos

- `index.html`: estrutura e textos da página.
- `style.css`: identidade visual, responsividade e animações.
- `script.js`: entrada dos elementos e progresso da linha do tempo.

## Personalização rápida

As principais cores ficam no início do arquivo `style.css`, dentro do bloco
`:root`. Os nomes e descrições dos serviços ficam nos elementos `<article>` do
arquivo `index.html`.

## Arquivos que não fazem parte do site

A pasta `.agents/` e o arquivo `skills-lock.json` são configurações de skills
usadas pelo agente de IA durante o desenvolvimento deste projeto. Eles não são
carregados pela página e não devem ser publicados junto com o site (basta
subir `index.html`, `style.css`, `script.js` e `foto.jpg`).
